# مرصد أذكاري

موقع دائم مجاني لعرض لوحة تحليلات المطوّر الخاصة بتطبيق أذكاري.

> هذه النسخة العامة تعرض بيانات توضيحية ثابتة. ربط البيانات الحقيقية يتطلب تشغيل واجهة التحليلات الخلفية وقاعدة البيانات الإنتاجية الموجودة في مستودع التطبيق.

## الرابط

بعد نجاح GitHub Pages سيكون الموقع متاحًا على:

`https://7oorof-hue.github.io/athkari-developer-observatory/`

## ما يعرضه الموقع

- الزوار والجلسات ومرات الفتح.
- الرسم البياني للنشاط حسب الفترة.
- فلترة 7 أو 30 يومًا والمنصة.
- الميزات الأكثر استخدامًا.
- مسار الاستخدام والاحتفاظ.
- ملخص CSV قابل للتنزيل.
- تنبيه واضح بأن البيانات المعروضة توضيحية.

## النشر

يتم النشر تلقائيًا عبر GitHub Actions عند كل تحديث لفرع `main`.
